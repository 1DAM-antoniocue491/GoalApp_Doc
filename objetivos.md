# Objetivos

El objetivo principal es crear una herramienta **intuitiva, funcional y accesible**, que facilite la organización y el seguimiento de competiciones de fútbol amateur, ofreciendo información actualizada en tiempo real y una experiencia de usuario clara tanto para administradores como para usuarios finales.

Además, el proyecto busca aplicar de forma práctica los conocimientos adquiridos en desarrollo de aplicaciones, cubriendo todas las fases de un proyecto real: **diseño, planificación, desarrollo frontend, backend, base de datos, API y trabajo en equipo.**
