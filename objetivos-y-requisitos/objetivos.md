# Objetivos

#### Objetivos generales

El objetivo principal de este proyecto es desarrollar una **aplicación multiplataforma para la gestión de ligas amateur de fútbol**, que permita administrar de forma centralizada usuarios, ligas, equipos, jugadores y partidos, garantizando seguridad, usabilidad y escalabilidad.

De forma más concreta, el proyecto persigue los siguientes objetivos generales:

* Facilitar la **organización y administración de competiciones deportivas amateur** mediante una herramienta digital accesible.
* Garantizar una **gestión segura de usuarios**, aplicando autenticación y control de acceso basado en roles.
* Optimizar el **registro, seguimiento y consulta de partidos**, resultados y eventos.
* Proporcionar **clasificaciones y estadísticas automáticas** basadas en los datos registrados.
* Ofrecer una **experiencia de usuario intuitiva**, adecuada para perfiles no técnicos.
* Diseñar una solución **escalable y mantenible**, preparada para futuras ampliaciones.
