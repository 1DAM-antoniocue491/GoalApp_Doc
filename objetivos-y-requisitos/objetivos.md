# Objetivos

#### Objetivos generales

El objetivo principal de este proyecto es desarrollar una **aplicación multiplataforma para la gestión de ligas amateur de fútbol**, que permita administrar de forma centralizada usuarios, ligas, equipos, jugadores y partidos, garantizando seguridad, usabilidad y escalabilidad.

De forma más concreta, el proyecto persigue los siguientes objetivos generales:

* Facilitar la **organización y administración de competiciones deportivas amateur** mediante una herramienta digital accesible.
* Garantizar una **gestión segura de usuarios**, aplicando autenticación y control de acceso basado en roles.
* Optimizar el **registro, seguimiento y consulta de partidos**, resultados y eventos.
* Proporcionar **clasificaciones y estadísticas automáticas** basadas en los datos registrados.
* Ofrecer una **experiencia de usuario intuitiva**, adecuada para perfiles no técnicos.
* Diseñar una solución **escalable y mantenible**, preparada para futuras ampliaciones.

#### Objetivos específicos

Los objetivos específicos detallan de forma concreta las funcionalidades que debe cubrir la aplicación para alcanzar los objetivos generales definidos.

| ID Objetivo | Nombre del objetivo                 | Descripción                                                                                                                                                    |
| ----------- | ----------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| OBJ-1       | Gestión de usuarios y autenticación | Permitir el registro, autenticación y control de acceso de los usuarios mediante roles diferenciados (administrador, entrenador, delegado de campo y jugador). |
| OBJ-2       | Gestión de roles y permisos         | Restringir el acceso a funcionalidades según el rol del usuario, garantizando la seguridad y correcta utilización del sistema.                                 |
| OBJ-3       | Gestión de ligas                    | Crear y administrar ligas personalizadas, configurando sus parámetros básicos y responsables de gestión.                                                       |
| OBJ-4       | Gestión de equipos                  | Crear equipos dentro de una liga y asignar a cada uno un entrenador y un delegado de campo.                                                                    |
| OBJ-5       | Gestión de jugadores                | Registrar jugadores como usuarios del sistema y asociarlos a equipos y ligas, almacenando su información básica.                                               |
| OBJ-6       | Gestión de partidos                 | Crear, programar y administrar partidos, controlando su estado durante todo su ciclo de vida.                                                                  |
| OBJ-7       | Registro de eventos del partido     | Permitir al delegado de campo registrar eventos como goles, tarjetas y cambios durante el partido.                                                             |
| OBJ-8       | Generación de clasificaciones       | Calcular y actualizar automáticamente la clasificación de la liga a partir de los resultados de los partidos.                                                  |
| OBJ-9       | Gestión de estadísticas             | Generar estadísticas individuales de jugadores y estadísticas globales por equipo o liga.                                                                      |
| OBJ-10      | Consulta de información             | Permitir a los usuarios consultar datos, resultados, clasificaciones y estadísticas de forma clara y accesible.                                                |
