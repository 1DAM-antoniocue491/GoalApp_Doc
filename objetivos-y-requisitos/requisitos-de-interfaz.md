# Requisitos de interfaz

**RNUI-1: Pantallas principales**\
La aplicación debe contar con pantallas claramente diferenciadas: login, home, ligas, equipos, jugadores, partidos, clasificaciones y estadísticas. Cada pantalla debe mostrar la información más relevante sin sobrecargar al usuario, manteniendo la claridad y facilidad de uso.

**RNUI-2: Navegación**\
La navegación entre pantallas debe ser intuitiva mediante menús, botones o barras de navegación. Los usuarios deben poder volver atrás fácilmente y contar con indicadores de progreso cuando estén creando ligas o registrando datos.

**RNUI-3: Consistencia visual**\
Toda la app debe mantener un estilo visual consistente: colores, tipografía, botones e iconografía. Se deben usar componentes reutilizables para mantener coherencia y facilitar la comprensión de acciones como editar, eliminar o agregar información.

**RNUI-4: Formularios y validaciones**\
Los formularios para registrar ligas, equipos, y partidos deben ser claros y fáciles de completar. Se mostrarán mensajes de error visibles e intuitivos, y se validarán campos obligatorios en tiempo real, como nombre del equipo o dorsal del jugador.

**RNUI-5: Accesibilidad**\
La app debe ser accesible para todos los usuarios: contraste adecuado para facilitar la lectura, compatibilidad con lectores de pantalla y botones con tamaño suficiente para una interacción cómoda en dispositivos móviles.

**RNUI-6: Visualización de datos**\
Las tablas y listados (clasificaciones, resultados y estadísticas) deben ser claros, con opciones para ordenar y filtrar información fácilmente. Además, se deben incluir indicadores visuales para eventos importantes como goles, tarjetas o cambios.

**RNUI-7: Compatibilidad multiplataforma**\
La interfaz debe adaptarse correctamente a distintos tamaños de pantalla en Android e iOS, manteniendo la misma estructura y estilo en la versión web.

**RNUI-8: Feedback al usuario**\
La app debe proporcionar retroalimentación constante al usuario: confirmaciones tras guardar o eliminar datos, indicadores de carga mientras se procesan acciones y alertas en caso de errores o intentos de acciones no permitidas según el rol.

**RNUI-9: Personalización mínima**\
Se debe permitir cierta personalización, como subir el escudo de un equipo, cambiar colores representativos y visualizar el perfil de usuario con foto y estadísticas resumidas.
