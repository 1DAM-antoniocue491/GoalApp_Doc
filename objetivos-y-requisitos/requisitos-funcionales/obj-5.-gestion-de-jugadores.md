# OBJ-5. Gestión de jugadores

Este objetivo permite registrar jugadores dentro del sistema, tratándolos como usuarios con información asociada. Incluye la gestión de sus datos básicos y su vinculación a equipos y ligas, de forma que puedan participar correctamente en la competición.
