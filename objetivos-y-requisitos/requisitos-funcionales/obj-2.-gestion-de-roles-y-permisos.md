# OBJ-2. Gestión de roles y permisos

Este objetivo se centra en definir y aplicar restricciones de acceso según el rol del usuario. Garantiza que cada perfil (administrador, entrenador, delegado de campo y jugador) pueda utilizar únicamente las funciones permitidas, reforzando la seguridad y evitando el uso incorrecto de funcionalidades críticas.

| ID    | Nombre                                                 | Descripción                                                                                                                                                         | Roles implicados                                      | Prioridad |
| ----- | ------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------- | --------- |
| RF-26 | Definición de roles disponibles en el sistema          | El sistema permitirá al administrador definir los roles disponibles (administrador, entrenador, delegado de campo y jugador) para su asignación a los usuarios.     | Administrador                                         | Alta      |
| RF-27 | Asignación de roles a usuarios por el administrador    | El sistema permitirá al administrador asignar un rol específico a cada usuario registrado.                                                                          | Administrador                                         | Alta      |
| RF-28 | Modificación de roles de usuarios existentes           | El sistema permitirá al administrador modificar el rol de un usuario, respetando las restricciones según el estado de la liga (en creación, en juego o finalizada). | Administrador                                         | Alta      |
| RF-29 | Eliminación o desactivación de roles                   | El sistema permitirá al administrador desactivar roles cuando sea necesario, siempre que no afecte a ligas en estado **en juego**.                                  | Administrador                                         | Media     |
| RF-30 | Control de acceso a funcionalidades según rol          | El sistema controlará el acceso a las funcionalidades disponibles según el rol del usuario autenticado.                                                             | Administrador, Entrenador, Delegado de campo, Jugador | Alta      |
| RF-31 | Restricción de acceso según estado de la liga          | El sistema limitará el acceso a ciertas funcionalidades en función del estado de la liga (en creación, en juego o finalizada).                                      | Administrador, Entrenador, Delegado de campo, Jugador | Alta      |
| RF-32 | Visualización dinámica de opciones según rol y estado  | El sistema mostrará únicamente las opciones disponibles según el rol del usuario y el estado actual de la liga.                                                     | Administrador, Entrenador, Delegado de campo, Jugador | Media     |
| RF-33 | Roles múltiples por usuario en distintas ligas         | El sistema permitirá que un usuario disponga de distintos roles en diferentes ligas de forma simultánea.                                                            | Administrador                                         | Media     |
| RF-34 | Prevención de acciones no permitidas por rol           | El sistema impedirá que un usuario ejecute acciones no permitidas por su rol.                                                                                       | Administrador, Entrenador, Delegado de campo, Jugador | Alta      |
| RF-35 | Registro de cambios en roles y permisos                | El sistema registrará las modificaciones de roles y permisos de los usuarios para auditoría.                                                                        | Administrador                                         | Media     |
| RF-36 | Reasignación de permisos al reactivar una liga         | El sistema permitirá actualizar y reasignar permisos de usuarios cuando una liga finalizada se reactive al estado **en creación**.                                  | Administrador                                         | Media     |
| RF-37 | Validación de permisos antes de iniciar la liga        | El sistema validará que los roles y permisos estén correctamente asignados antes de que una liga cambie al estado **en juego**.                                     | Administrador                                         | Media     |
| RF-38 | Bloqueo de cambios de rol durante la liga en juego     | El sistema impedirá modificar los roles de los usuarios mientras la liga esté en estado **en juego**, salvo por el administrador.                                   | Administrador                                         | Alta      |
| RF-39 | Notificación a usuarios sobre cambios de permisos      | El sistema notificará automáticamente a los usuarios cuando sus roles o permisos cambien.                                                                           | Administrador, Entrenador, Delegado de campo, Jugador | Media     |
| RF-40 | Verificación de consistencia de roles al crear usuario | El sistema comprobará que el rol asignado a un nuevo usuario sea válido y consistente con la configuración actual.                                                  | Administrador                                         | Alta      |
| RF-41 | Reutilización de roles y permisos en nuevas ligas      | El sistema permitirá reutilizar la configuración de roles y permisos al crear nuevas ligas.                                                                         | Administrador                                         | Media     |
| RF-42 | Auditoría de accesos y acciones por rol                | El sistema permitirá auditar accesos y acciones realizadas por los usuarios según su rol.                                                                           | Administrador                                         | Media     |
| RF-43 | Restauración de permisos al reactivar ligas            | El sistema permitirá restaurar los permisos que tenían los usuarios antes de que una liga finalizada sea reactivada.                                                | Administrador                                         | Media     |
