# OBJ-3. Gestión de ligas

Este objetivo incluye las funcionalidades necesarias para crear y administrar ligas de fútbol. Permite configurar sus datos principales, asignar responsables de gestión y definir parámetros básicos para que la competición pueda ser organizada correctamente desde el sistema.
