# OBJ-3. Gestión de ligas

Este objetivo incluye las funcionalidades necesarias para crear y administrar ligas de fútbol. Permite configurar sus datos principales, asignar responsables de gestión y definir parámetros básicos para que la competición pueda ser organizada correctamente desde el sistema.

| ID    | Nombre                                         | Descripción                                                                                                                                                                                                       | Roles implicados                                      | Prioridad |
| ----- | ---------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------- | --------- |
| RF-44 | Crear liga                                     | El sistema permitirá al administrador crear una nueva liga introduciendo nombre, descripción, temporada, ubicación opcional y número máximo de equipos. La liga se creará inicialmente en estado **En creación**. | Administrador                                         | Alta      |
| RF-45 | Validar datos obligatorios de liga             | El sistema validará que el nombre de la liga sea obligatorio, único dentro del sistema, y que el número máximo de equipos sea mayor que cero.                                                                     | Administrador                                         | Alta      |
| RF-46 | Editar información básica de la liga           | El sistema permitirá modificar nombre, descripción, temporada y ubicación de la liga únicamente cuando se encuentre en estado **En creación**.                                                                    | Administrador                                         | Alta      |
| RF-47 | Bloquear edición de liga en juego o finalizada | El sistema impedirá la modificación de datos estructurales de una liga cuando su estado sea **En juego** o **Finalizada**.                                                                                        | Administrador                                         | Alta      |
| RF-48 | Eliminar liga sin dependencias                 | El sistema permitirá eliminar una liga solo si está en estado **En creación** y no tiene equipos, partidos ni usuarios asociados.                                                                                 | Administrador                                         | Media     |
| RF-49 | Impedir eliminación de liga con datos o activa | El sistema bloqueará la eliminación de ligas que estén en estado **En juego** o **Finalizada**, o que contengan datos asociados.                                                                                  | Administrador                                         | Alta      |
| RF-50 | Definir sistema de puntuación                  | El sistema permitirá configurar el sistema de puntuación de la liga (victoria, empate, derrota) antes de iniciar la competición.                                                                                  | Administrador                                         | Alta      |
| RF-51 | Configurar criterios de desempate              | El sistema permitirá definir criterios de desempate (diferencia de goles, goles a favor, enfrentamientos directos, etc.) durante el estado **En creación**.                                                       | Administrador                                         | Media     |
| RF-52 | Configurar formato de competición              | El sistema permitirá definir el formato de competición (liga simple, ida/vuelta, grupos) durante el estado **En creación**.                                                                                       | Administrador                                         | Media     |
| RF-53 | Cambiar estado a “En juego”                    | El sistema permitirá iniciar la liga cambiando su estado a **En juego**, siempre que cumpla las condiciones mínimas establecidas.                                                                                 | Administrador                                         | Alta      |
| RF-54 | Validar condiciones para iniciar liga          | El sistema verificará que la liga tenga al menos dos equipos y un calendario válido antes de permitir el cambio a estado **En juego**.                                                                            | Administrador                                         | Alta      |
| RF-55 | Cambiar estado a “Finalizada”                  | El sistema permitirá finalizar una liga cuando todos los partidos hayan sido disputados o cuando el administrador lo decida explícitamente.                                                                       | Administrador                                         | Media     |
| RF-56 | Bloquear acciones tras finalizar liga          | El sistema impedirá la creación o modificación de partidos y equipos cuando la liga esté en estado **Finalizada**.                                                                                                | Administrador                                         | Alta      |
| RF-57 | Asignar responsables de liga                   | El sistema permitirá asignar usuarios como responsables secundarios de una liga con permisos limitados de gestión.                                                                                                | Administrador                                         | Media     |
| RF-58 | Revocar permisos de responsables de liga       | El sistema permitirá retirar el rol de responsable de liga a un usuario, respetando las restricciones por estado de liga.                                                                                         | Administrador                                         | Media     |
| RF-59 | Asociar entrenadores a la liga                 | El sistema permitirá vincular entrenadores a una liga para que puedan gestionar sus equipos.                                                                                                                      | Administrador                                         | Alta      |
| RF-60 | Asociar delegados de campo a la liga           | El sistema permitirá vincular delegados de campo a una liga para la gestión de eventos de partidos.                                                                                                               | Administrador                                         | Alta      |
| RF-61 | Consultar detalles de liga                     | El sistema permitirá consultar información detallada de una liga: estado, reglas, equipos, calendario y clasificación.                                                                                            | Administrador, Entrenador, Delegado de campo, Jugador | Alta      |
| RF-62 | Listar ligas visibles                          | El sistema permitirá listar ligas según su estado (**En creación**, **En juego**, **Finalizada**) y según los permisos del usuario.                                                                               | Administrador, Entrenador, Delegado de campo, Jugador | Alta      |
| RF-63 | Controlar visibilidad de ligas privadas        | El sistema permitirá marcar una liga como privada, restringiendo su visibilidad solo a usuarios asociados.                                                                                                        | Administrador                                         | Media     |
| RF-64 | Unirse a liga mediante invitación              | El sistema permitirá que un usuario se una a una liga privada mediante una invitación o código generado por el administrador.                                                                                     | Administrador, Entrenador                             | Media     |
| RF-65 | Salir de una liga                              | El sistema permitirá desvincular a un usuario de una liga siempre que no tenga responsabilidades activas dentro de ella.                                                                                          | Administrador                                         | Baja      |
| RF-66 | Registrar fecha de inicio y fin                | El sistema almacenará automáticamente la fecha de inicio al pasar la liga a estado **En juego** y la fecha de cierre al finalizarla.                                                                              | Sistema                                               | Media     |
| RF-67 | Auditar cambios en la liga                     | El sistema registrará los cambios relevantes realizados sobre la liga (estado, reglas, responsables).                                                                                                             | Sistema                                               | Baja      |
| RF-68 | Restringir gestión de liga por rol             | El sistema garantizará que solo usuarios con rol autorizado puedan crear, modificar o eliminar ligas.                                                                                                             | Sistema                                               | Alta      |
