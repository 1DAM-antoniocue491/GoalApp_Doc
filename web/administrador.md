# Qué aplicación hace y la función

El objetivo de esta aplicación es gestionar tu liga de amigos desde el primer día. Además, cuenta con una función educativa para enseñar fútbol a niños y adultos, con roles específicos para administradores, delegados, entrenadores, jugadores y usuarios.

  

Es fundamental que la aplicación permita el acceso sin registro previo (modo invitado). De esta manera, el usuario puede explorar las funciones y comprobar que la herramienta es útil antes de crear una cuenta.

  

La aplicación permite el acceso total a las ligas mediante un perfil de observador. En este modo, el usuario puede explorar todas las funciones y apartados para entender cómo trabaja la app, pero sin permisos de edición, garantizando que no se modifique ningún dato real durante la prueba.

# Calendario

Desde esta pantalla se visualizan todos los encuentros, permitiendo configurar el formato de competición en formato de liga a una o dos vueltas (ida y vuelta), con la opción de visualizar los partidos en directo.

Además del generador automático, el sistema ofrece la opción de creación manual de encuentros, permitiendo organizar partidos específicos según las necesidades de la liga.


Dentro de la liga que creamos anteriormente, definiremos las reglas de juego. Organizaremos más de ocho partidos semanales, concentrando las jornadas en viernes, sábado y domingo. Todos los encuentros comenzarán a las 20:00 (8 de la tarde), para que al terminar podamos disfrutar de unas tapas y cervezas. 


Darmos a guardada.

El acceso a la creación de calendarios está restringido. Los usuarios estándar no tienen permisos de edición; su función es únicamente de consulta de los calendarios generados por los administradores.

Una vez creados los equipos, el sistema proyecta el calendario íntegro de la competición. Para una liga de 16 equipos, por ejemplo, se generarán 30 jornadas, asegurando que cada conjunto juegue dos veces contra cada rival (local y visitante). 


Finalmente, el apartado más consultado por los usuarios es la clasificación. Esta tabla interactiva muestra la posición de cada equipo basándose en sus puntos y estadísticas acumuladas.

Aquí disponemos del método de creación manual: permite configurar el encuentro seleccionando el día, la hora y los equipos que jugarán como local y visitante.


Y por último a crear un nuevo partido.


Una vez generado el calendario, se habilita la gestión de la convocatoria. Aquí, el entrenador puede seleccionar y llamar a los jugadores necesarios para disputar cada partido específico.


El sistema permite modificar las fechas del calendario ante imprevistos meteorológicos. Por ejemplo, en caso de lluvias intensas que impidan el juego por peligro, el administrador puede aplazar los partidos para garantizar la seguridad de los participantes.

Una vez llegada la hora programada, el sistema permite iniciar el partido. En ese momento, se habilita el cronómetro y el acta en vivo para comenzar a registrar los sucesos del encuentro. 


Una vez validadas las plantillas, el sistema permite la introducción del marcador. El motor de la liga está preparado para procesar victorias, derrotas o empates, actualizando la clasificación de forma automática.



Con los partidos iniciados, se pueden realizar varias acciones: primero, registrar eventos (como un gol); segundo, consultar la convocatoria y, por último, finalizar el partido para guardar el resultado.

# Tabla

La tabla de clasificación es universal e invariable. Independientemente de los permisos del usuario (administrador o estándar), la información visualizada es la misma.

El sistema recalcula la tabla automáticamente tras cada jornada, modificando las posiciones en función de los resultados obtenidos (victorias, derrotas o empates) por todos los equipos participantes. 


La función más destacada es la posibilidad de registrar un equipo personalizado, permitiendo gestionar sus partidos y seguir su evolución a lo largo de las jornadas.


En esta sección se encuentra el listado completo de los equipos registrados en la liga. 


La aplicación permite acceder a la información detallada de cada equipo. En su ficha se puede consultar el nombre del club, la lista de jugadores, las estadísticas acumuladas y el entrenador, cuya figura es clave para gestionar el sistema de invitaciones.

## Sistemas de Gestión de Participantes

Para garantizar que ningún equipo se quede fuera, la plataforma ofrece dos métodos de inscripción de personal:

### 1. Sistema Jerárquico (Delegación)

Este es el método recomendado para ligas grandes, ya que distribuye la carga de trabajo.

- Paso 1: El Administrador invita al Entrenador.
    
- Paso 2: El Entrenador toma el control de su equipo y asigna a sus Delegados y Platilla.
    
- Ventaja: Automatización y responsabilidad compartida. Cada equipo es responsable de su propia veracidad de datos.
    

### 2. Sistema de "Fuerza Bruta" (Gestión Directa)

Este método está diseñado para el Administrador que necesita control total o cuando los equipos no tienen soltura tecnológica.

- Acción: El Administrador crea manualmente los perfiles de entrenadores, delegados y cada uno de los jugadores.
    
- Uso: Ideal para correcciones de última hora, inscripciones presenciales o para asegurar que la liga arranque en la fecha prevista sin depender de terceros.
    
- Ventaja: Control absoluto y rapidez en la configuración inicial si los datos ya se tienen físicamente.
    

Desde aquí puedes invitar a otros usuarios para que se unan a la liga con el rol de entrenador. 


Existe un tercer método de invitación mediante código. El administrador genera un código único para cada equipo; el entrenador o los jugadores solo tienen que introducirlo en la aplicación para unirse automáticamente a su plantilla. 


Este es el código generado para que una persona se una al equipo. Se puede compartir a través de redes sociales como WhatsApp, o por servidores de Discord, facilitando el envío de persona a persona.
