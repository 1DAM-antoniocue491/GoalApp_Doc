# Tecnologías y herramientas

#### **Frontend**

* **React Native + Expo**
  * Framework para desarrollo móvil multiplataforma (iOS, Android) con un solo código base.
  * Permite crear **interfaces dinámicas y adaptables** con componentes reutilizables.
  * Expo facilita la **compilación y despliegue rápido** en dispositivos reales y simuladores.
* **React**
  * Framework para el desarrollo frontend web.
  * Permite crear **interfaces dinámicas y adaptables** con componentes reutilizables.
* **React Navigation**
  * Gestión de rutas y navegación entre pantallas dentro de la app.
* **Tailwind CSS**
  * Para diseño de interfaz y estilos consistentes, adaptables a distintos tamaños de pantalla.

#### **Backend**

* **FastAPI (Python)**
  * Framework ligero y moderno para crear APIs REST.
  * Soporta **tipado y validación de datos** con Pydantic.
  * Permite documentar automáticamente la API con Swagger.
* **ORM: SQLAlchemy**
  * Facilita la interacción con la base de datos sin escribir SQL puro.
  * Soporta relaciones complejas, migraciones y consultas eficientes.
* **Autenticación y seguridad**
  * JWT (JSON Web Tokens) para gestionar sesiones y permisos de usuarios.

#### **Base de datos**

* PostGreSQL
  *   Base de datos relacional robusta, segura y altamente escalable, adecuada para aplicaciones web y móviles.


  *   Ofrece soporte para integridad referencial, claves foráneas, transacciones y procedimientos almacenados, garantizando una gestión consistente y fiable de los datos.


  * Además, permite realizar consultas complejas y procesar grandes volúmenes de información, facilitando la generación de estadísticas y el análisis avanzado de datos.
* **Scripts y migraciones**
  * Scripts SQL para creación de tablas y relaciones.
  * Herramientas para migraciones que mantienen la base de datos sincronizada con el modelo de datos.

#### **Herramientas adicionales**

* **Taiga**
  * Organización de tareas, backlog, registro de actividades y documentación interna del equipo.
* **Git / GitHub**
  * Control de versiones, colaboración en equipo y gestión de ramas.
* **GitBook**
  * Documentación oficial del proyecto, organizada por partes y páginas.
* **Hosting / Despliegue**
  * Render para desplegar el backend y web.
  * Exportación de la app para Android / iOS a través de Expo.
* **Herramientas gráficas**
  * Para diagramas ER, mockups o prototipos (Draw.io, Figma o similares).

***

#### **Consideraciones sobre la elección de tecnologías**

* Se eligieron **tecnologías modernas y ampliamente utilizadas**, que permiten desarrollar de manera ágil y multiplataforma.
* Se priorizó **simplicidad, escalabilidad y mantenimiento** del proyecto.
* Todas las tecnologías permiten **documentación clara, integración con Git y pruebas automáticas**, facilitando la entrega final y posibles ampliaciones futuras.
